# Execution Documentation

## Environment
- Platform: Google Colab
- Language: Python
- LLM Provider: Groq

## Experiment 1: Memory Server

The experiment uses an MCP server and Python client.

Implemented operations:
1. Save a note.
2. Search notes.
3. List notes.
4. Update notes.
5. Delete notes.

Notes are stored in a JSON file.

## Experiment 2: Weather Connector

The experiment uses an MCP server and Streamlit.

Implemented functionality:
1. Accept a weather question.
2. Send the question and tool schema to Groq.
3. Select the weather tool.
4. Retrieve weather information from wttr.in.
5. Return the result to Groq.
6. Display the final response.
